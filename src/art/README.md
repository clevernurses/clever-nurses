# Original CleveRNurses artwork

Drop each infographic image here (any of .webp, .jpg, .png) using the exact file name in `artwork.file`
(see src/data/etsyResources.ts), e.g. `how-blood-flows-through-the-heart.jpg`.
.jpg, .png and .webp all work; only the base name has to match.

Files found here replace the "artwork pending" placeholder automatically on the next build.
Use web-sized exports (about 1600px on the long side, under 400 KB) and keep the full-resolution
print files off the website. The website shows previews; the printable stays on Etsy.
